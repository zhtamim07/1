# Better xCloud iOS

An enhanced iOS wrapper for [Xbox Cloud Gaming](https://www.xbox.com/play), bringing the power of **Better xCloud** to iPhone and iPad.

## ✨ Features

This app implements **39 features** for the ultimate cloud gaming experience:

*   **📺 Visual Excellence**: Force 1080p, High-profile H.264 codec, Clarity Boost, and Video Filters (Brightness/Contrast/Saturation).
*   **🎮 Virtual Controller**: Play any game without a physical gamepad. Includes customizable styles (Muted/White/Default) and adjustable opacity.
*   **📊 Stream Statistics**: Real-time HUD showing FPS, RTT (Latency), Jitter, Bitrate, and Battery level.
*   **🔊 Audio Enhancements**: Volume Boost (up to 600%) and auto-enable microphone on game launch.
*   **⚡ Optimization**: Skip Xbox splash video, reduce UI animations, and disable social features for faster loading.
*   **🛠️ Advanced Controls**: Aspect Ratio control (16:9, 4:3, Fill), Max Bitrate cap, and Server Region picker.
*   **📱 Native Integration**: Background audio support, specialized iOS WebView patches, and wakelock to prevent screen sleep.

## 🚀 How to Build (GitHub Actions)

You don't need a Mac to get the `.ipa` file! We've included a GitHub Actions workflow:

1.  Go to the **Actions** tab in this repository.
2.  Select the **🎉 iOS Build** workflow.
3.  Click **Run workflow**.
4.  Once completed, the sideloadable `.ipa` will be available in the **Releases** section.
